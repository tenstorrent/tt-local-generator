How it works

The pipeline

A single workflow JSON drives all six phases. Each model runs once — chip loads are amortized across all five fairs. No manual steps between phases.

local · no inference needed
On forge / CPU utility steps: Background removal (RMBG), captioning (BLIP), and depth estimation (GLPN) run on CPU via the tenstorrent Python venv. For this pipeline the depth map is the only utility step kept — and only for closed interiors where depth conditioning helps SkyReels I2V. Background removal was removed entirely: for scene-based historical photography the background is the narrative, not noise. BLIP was removed because the manually-researched prompts already carry far more historical specificity than any auto-caption could.
